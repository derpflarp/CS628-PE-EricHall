# CS628-PE-EricHall

# Input

The input for this application is the resume information stored within the `Resume.js` component. This includes the user's name, contact information, education, technical skills, work experience, and project descriptions. The application also uses styling rules defined in `Resume.css` to control the appearance and layout of the resume. No data is entered by the user while the application is running.

# Process

When the application starts, React renders the `App` component, which imports and displays the `Resume` component. The resume data is organized into sections using JSX elements such as headers, paragraphs, lists, and links. The `Resume.css` stylesheet formats these elements by applying colors, fonts, spacing, and alignment to create a clean, professional-looking resume webpage.

# Output

The output is a single-page resume displayed in the user's web browser. The page presents the user's personal information, education, skills, work experience, and projects using a structured layout with a bright green background and black text. The completed webpage allows users to easily read the resume, and any project links can be opened in a new browser tab.
